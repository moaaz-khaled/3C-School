## 🎮 Game Idea

`Roll Ball` is a simple 3D game built with Unity. Control a rolling ball inside the level and hit the cubes to destroy them and earn as many points as possible.

Be careful: hitting a capsule ends the game immediately and displays the **Game Over** screen.

## 🎯 Objective

- Hit the cubes to destroy them.
- Get the highest Score possible.
- Avoid the capsules throughout the game.
- Complete the level successfully.

## 🕹️ How to Play

1. Start the game from the start screen.
2. Move the ball around the level.
3. Hit the cubes to destroy them and increase your score.
4. Stay away from the capsules, because hitting one causes **Game Over**.
5. Keep playing until you complete the level objectives.

## 📏 Game Rules

| Element | Result |
| --- | --- |
| 🟪 Cube | Destroyed and increases the Score |
| 🔵 Capsule | Displays the Game Over screen |
| 🟢 Player Ball | Controlled by the player |

## 🚀 How to Run

1. Download or extract the required Session version.
2. Open the project using Unity Hub.
3. Open the main Scene.
4. Press the **Play** button in Unity.
5. Try to destroy the cubes while avoiding the capsules.

## 📚 Learning Goals

- Working with Unity Scenes.
- Moving an object in a 3D environment.
- Detecting collisions between objects.
- Destroying objects during gameplay.
- Updating and displaying the Score.
- Creating winning and losing states.
- Using UI to display game results.
