A creative and structured educational repository for teaching game development using Unity. This repository contains lesson slides, student activities, quiz materials, and ready-to-use game assets designed for different learning levels.

## 🌟 Overview

This project was created to support instructors and students in the 3C School learning journey. It includes:

- Unity lesson sessions for multiple levels
- Course slides for each class
- Game assets, textures, materials, SFX, and prefabs
- Interactive quizzes for practice and assessment
- Ready-made learning structure for classroom use

## 🎯 Purpose

The main goal of this repository is to make learning easier, more organized, and more engaging for students who are learning:

- Unity basics
- Game design concepts
- 2D/3D game elements
- Assets and materials
- Game mechanics and interaction
- Practice through quizzes and exercises

## 🧩 Learning Tracks

### Level 1
Focuses on the fundamentals of Unity and beginner game development. This level introduces the learner to core concepts and simple interactive projects.

Typical topics:
- Unity interface
- Scene setup
- Basic objects and transforms
- Simple game logic
- Introductory gameplay mechanics

### Level 2
Builds on the basics and introduces more advanced game creation, assets, and interactive elements.

Typical topics:
- More complex object interaction
- Game props and prefabs
- Visual effects and particle systems
- Environment design
- Audio and asset integration

### Level 3
Covers more advanced and polished game development practices, including character systems, enemy design, environmental assets, and UI/VFX.

Typical topics:
- Character and enemy assets
- Environment composition
- UI elements
- VFX and animations
- More advanced project structure

## 🧠 Quiz Section

The repository includes a dedicated quiz section to help students review what they learned.

- Practice questions by level
- Quick assessment for students
- Instructor-friendly classroom support
- Useful for revision and challenge activities

## 🎨 Included Content Types

This repository includes a wide range of educational and creative resources such as:

- Slide presentations
- Unity project materials
- 3D models and prefab assets
- Textures and materials
- Sound effects (SFX)
- UI resources
- Visual effects (VFX)
- Image assets and project references

## 🚀 Recommended Use

1. Start with the session slides in the relevant Unity level folder.
2. Review the assets and project materials alongside the lessons.
3. Use the quiz folder to test understanding.
4. Repeat the course flow by level for gradual learning progress.

## 🏫 For Instructors

This repository is designed to support classroom teaching and structured lesson planning. Instructors can:

- present lessons from the session files,
- use the assets directly in practical demos,
- assign quizzes to students,
- organize training by difficulty level.

## 💡 Notes

This content is intended for educational and training purposes. It is a growing learning repository that can be expanded with more lessons, assets, activities, and assessments over time.

## ✨ Project Philosophy

3C School is about building creative thinkers and makers through practical, hands-on game development learning. The repository reflects that spirit by combining theory, practice, and creative production in one place.
